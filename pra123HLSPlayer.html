📖 Latency Metrics Definitions (v3.0)

1. Playlist Latency

The buffer depth - how far behind the live edge (last available fragment) the player is currently operating.

Playlist Latency = Last Fragment Start Time - Current Fragment Start Time

This indicates the amount of buffered content available between the current playback position and the most recent fragment in the playlist.

2. Playhead vs Device Time

Time difference between the estimated real-world time of the current playback position and the device clock.

Playhead Difference = Device Time - Estimated Playhead DateTime

This shows how far in the past (relative to device time) the content being played was originally broadcast.

3. Playlist End vs Device Time

Time difference between the estimated real-world time of the last fragment's end and the device clock.

Playlist End Difference = Device Time - (Last Fragment PDT + Duration)

This shows how recent the latest available content is compared to the current device time.

4. HLS.js Configuration Parameters

liveSyncDurationCount: Number of target duration intervals from the playlist end that the player should maintain as buffer.

liveSyncDuration: The actual duration in seconds that the player targets for live sync position.

liveMaxLatencyDurationCount: Maximum latency threshold in terms of target duration count.

liveMaxLatencyDuration: Maximum latency threshold in seconds.

5. Player Latency Properties

targetLatency: The target latency the player is trying to maintain (read from player instance).

latency: The current actual latency of the player (read from player instance).

maxLatency: The maximum latency threshold (read from player instance).

⚠️ Important: Time-based metrics require #EXT-X-PROGRAM-DATE-TIME tags in the HLS manifest. Without these tags, the display will show "N/A (no PDT)".
📝 Note: The "Remove" buttons allow you to test player behavior without certain parameters:
  • Remove liveSyncDurationCount: Removes both liveSyncDurationCount and liveMaxLatencyDurationCount
  • Remove liveSyncDuration: Removes both liveSyncDuration and liveMaxLatencyDuration
This lets HLS.js use its default synchronization logic.
